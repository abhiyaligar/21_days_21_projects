# Image Colorization using U-Net

This project implements an image colorization pipeline using a U-Net architecture. The model takes grayscale images as input and predicts the corresponding colored version. It leverages PyTorch for deep learning, along with supporting libraries for image preprocessing and evaluation.

## Features

- Converts grayscale images into realistic colored images  
- U-Net based encoder-decoder architecture  
- Uses LAB color space for color prediction  
- Dataset loading and preprocessing pipeline with PyTorch  
- Training loop with loss monitoring  

## Tech Stack

- Python  
- PyTorch  
- Torchvision  
- NumPy  
- scikit-image  
- PIL (Pillow)
